# AITUKU-RU

ChatGPT の画像生成用に、X(Twitter)で出回っている「ちょいエロ」プロンプトを集めて、
自分のキャラに差し替えたプロンプトをワンタッチで作るツール。**スマホだけで使える**。

👉 https://omuthviman-wq.github.io/AITUKU-RU/

## できること

1. **キャラ記憶** — 名前・見た目プロンプト・補足・参考画像を保存。上のセレクトで切り替え。
2. **プロンプト一覧** — X から自動収集 / ツイートURL貼り付け / 手動追加。いいね順・お気に入り・絞り込み。
   Xのやつは生成サンプル画像・ツイート埋め込み表示・「Xで開く」リンク付き。
   最初から内蔵シーン(水着グラビア、ランジェリー、彼シャツ、バニー、メイド等)が10個入ってる。
3. **合成** — 「このキャラで作る」で、シーンの構図・衣装はそのまま人物だけ差し替えたプロンプトを表示。
4. **生成** — 「コピーしてChatGPTを開く」で ChatGPT の入力欄に流し込む。
   設定タブで OpenAI APIキーを入れると「AIで自然に合成」と「生成」ボタンでその場で画像生成できる。

露出は ChatGPT で通る範囲(水着・ランジェリーまで)を想定。キャラは成人のみ登録可。

## データの保存場所

キャラ・追加したプロンプト・APIキーは **スマホのブラウザ内(localStorage)だけ** に保存される。
リポジトリ(公開)には一切アップロードされない。ブラウザのデータを消すと消えるので、設定タブからたまにバックアップする。

## 初回セットアップ(スマホのブラウザで GitHub を開いて1回だけ)

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. **Actions** タブ → 「Xから収集して公開」→ **Run workflow**(数分で上のURLが開けるようになる)
3. 開いたら共有メニューから **ホーム画面に追加** するとアプリっぽく使える

### Xの自動収集を使う場合(任意)

X API は有料(Basic プラン以上)。

- **Settings → Secrets and variables → Actions → New repository secret** で `X_BEARER_TOKEN` を登録
- 毎朝6時ごろ自動で収集される。今すぐ集めたい時はアプリの「Xから収集」→ GitHub で Run workflow → 数分後に「最新を読み込む」
- 検索ワードを変えたい時は同じ画面の **Variables** に `X_QUERY` を登録

キーが無くても、ツイートURLを貼れば1件ずつ取り込める。
