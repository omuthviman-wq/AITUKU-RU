# AITUKU-RU

ChatGPT の画像生成用に、X(Twitter)で出回っている「ちょいエロ」プロンプトを集めて、
自分のキャラに差し替えたプロンプトをワンタッチで作るツール。

## できること

1. **キャラ記憶** — 名前・見た目プロンプト・補足・参考画像を保存。上のセレクトで切り替え。
2. **プロンプト一覧** — X から収集 / ツイートURL貼り付け / 手動追加。いいね順・お気に入り・絞り込み。
   最初から内蔵のシーン(水着グラビア、ランジェリー、彼シャツ、バニー、メイド等)が10個入ってる。
3. **合成** — 一覧から「このキャラで作る」で、シーンの構図・衣装はそのまま、人物だけ自分のキャラに置き換えたプロンプトを表示。
   「AIで自然に合成」を押すと OpenAI API で1本の自然な文章に書き直す。
4. **生成** — 「コピーしてChatGPTを開く」で ChatGPT の入力欄に流し込む。
   `OPENAI_API_KEY` があれば「生成」ボタンでその場で画像生成(参考画像があれば顔を寄せる)。

露出は ChatGPT で通る範囲(水着・ランジェリーまで)を想定。キャラは成人のみ登録可。

## 使い方

```bash
cp .env.example .env   # 必要ならキーを書く(無くても動く)
npm start              # → http://localhost:3000
```

Node.js 20 以上。依存パッケージなし。データは `data/` に保存される(git管理外)。
スマホから使う場合は、PCで起動して同じWi-Fiから `http://<PCのIP>:3000` を開く。

## キーについて

| 設定 | 無い場合 | ある場合 |
|---|---|---|
| `X_BEARER_TOKEN` | ツイートURLを貼って1件ずつ追加 | 「Xから収集」で検索して一括取得(X API の Basic 以上のプランが必要) |
| `OPENAI_API_KEY` | コピーして ChatGPT に貼る | AI合成・ワンボタン生成(API利用料がかかる。ChatGPT Plus とは別課金) |

検索ワードは `.env` の `X_QUERY` で変えられる。
