Xからの自動収集

GitHub Actions が毎朝6時ごろに X を検索して一覧を更新します。「Xから収集」ボタンを押すと今すぐ実行する画面(GitHub)が開くので、「Run workflow」を押してください。数分後に「最新を読み込む」で反映されます。
使うには GitHub の Settings → Secrets and variables → Actions に X_BEARER_TOKEN を登録してください(X API の有料プランが必要)。
