ワンボタン生成(OpenAI API)

Gemini APIキー(無料・おすすめ)

入れると「AIで自然に合成」が無料で使えます。Google AI Studio で Googleアカウントでログイン →「APIキーを作成」でコピーして貼ってください。無料枠は回数制限があり、送った内容が Google の改善に使われることがあります。

OpenAI APIキー(任意・有料)

入れると「生成」ボタンでその場で画像生成できます(Gemini キーが無い時は「AIで自然に合成」にも使います)。API利用料は ChatGPT Plus とは別に、使った分だけかかります。

キーはこのスマホのブラウザ内だけに保存され、Google / OpenAI 以外には送られません。

Xからの自動収集

GitHub Actions が毎朝6時ごろに X を検索して一覧を更新します。「Xから収集」ボタンを押すと今すぐ実行する画面(GitHub)が開くので、「Run workflow」を押してください。数分後に「最新を読み込む」で反映されます。
使うには GitHub の Settings → Secrets and variables → Actions に X_BEARER_TOKEN を登録してください(X API の有料プランが必要)。
